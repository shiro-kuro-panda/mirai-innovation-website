# 夢の職業絵本メーカー（MirAI塾）

夢職業診断 → 絵本づくり → ビジネスモデルキャンバス までを、コピー＆ペーストなしで
1つのアプリの中で完結させるツールです。

`index.html` を開くだけで動きます。ビルドもサーバーも要りません。

## なぜ Gemini Storybook を使っていないのか

Gemini アプリの Storybook は Gem（アプリ内機能）であり、**プログラムから呼び出せる公開APIがありません**。
そのため「アプリで生成したテキストを人がコピーして Storybook に貼る」という手作業が必ず発生します。

このアプリは Storybook を経由せず、**Gemini API を直接呼んで絵本の本文と挿絵をその場で生成**します。
これがコピペを不要にしている部分です。

## 全体の流れ

| ステップ | 内容 | 使うもの |
| --- | --- | --- |
| 1. 夢職業診断 | 5つの質問にチャットで答える | — |
| 2. 職業提案 | その子だけのオリジナル職業を提案 | Gemini（テキスト） |
| 3. 絵本づくり | 本文6ページ＋挿絵を生成し、めくり式で読む | Gemini（テキスト＋画像） |
| 4. おしごとの せっけいず | ビジネスモデルキャンバス9マスに展開 | Gemini（テキスト） |

絵本と BMC は「印刷・PDF保存」からそのまま持ち帰れます。読み上げはブラウザの音声合成を使います。

## 主人公の見た目をそろえる仕組み

挿絵をページごとに独立して生成すると、主人公の顔や服が毎ページ変わってしまいます。
そこで次の順で生成しています。

1. まず**キャラクター設定画**を1枚だけ生成する（白背景・全身・正面）
2. 各ページの挿絵は、**その設定画を参照画像として一緒に渡して**生成する

これで全ページの主人公がそろいます。設定画はそのまま表紙にも使っています。

## APIキーについて

初回に、画面右上の歯車から Gemini API キーを登録してください。
キーは <https://aistudio.google.com/apikey> で作成できます。

- キーは**その端末のブラウザ（localStorage）にのみ保存**され、Google 以外には送信されません
- 共用のパソコンで使った場合は、設定画面の「削除」を押してください
- キーを登録しなくても、診断と文章だけの絵本は動きます（挿絵とBMCはキーが必要です）

`file://` で直接開いた場合でも、Gemini API 側が `Origin: null` を許可しているため CORS で弾かれません。

## モデルの選び方

モデルID（`gemini-2.5-flash-image` など）は提供側の都合で入れ替わります。
そのためコード内で決め打ちせず、**キーで実際に使えるモデルを `ListModels` で取得してから選ぶ**ようにしています。
設定画面の「使えるモデルを確認する」で一覧を取得し、文章用・挿絵用を手動で選ぶこともできます。

優先順位（上から順に、使えるものを採用）:

- 文章：`gemini-2.5-flash` → `gemini-flash-latest` → `gemini-2.5-pro` → `gemini-2.0-flash`
- 挿絵：`gemini-3.1-flash-lite-image`（Nano Banana 2 Lite）→ `gemini-2.5-flash-image`（Nano Banana）

## あとからサーバー側にキーを移す場合

ネットワークに触れているのは `callGemini()` / `listModels()` の2つだけです。
一般公開して「利用者にキーを入力させたくない」場合は、この2つの向き先を自前のAPIルート
（例：Next.js の `/api/gemini`）に変え、キーの受け渡しを消すだけで移行できます。UI側の変更は不要です。

## 費用の目安

1冊につき画像生成が7枚（設定画1＋本文6）走ります。生成回数がそのまま費用になるので、
教室でまとめて使う場合は事前に Google AI Studio 側の利用上限を確認してください。
