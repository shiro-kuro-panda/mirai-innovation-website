# 夢の職業絵本メーカー（MirAI塾）

夢職業診断 → 絵本づくり → ビジネスモデルキャンバス までを、コピー＆ペーストなしで
1つのアプリの中で完結させるツールです。絵本は本文10ページ。

## 動かし方

`index.html` をブラウザで開くだけです。ビルドもサーバーも要りません。

ローカルサーバーで開きたい場合は、このフォルダで次を実行して
<http://localhost:8000> を開いてください。

```
python3 -m http.server 8000
```

初回は画面右上の歯車から Gemini API キーを登録してください。
キーは <https://aistudio.google.com/apikey> で無料で作成できます。

- キーは**その端末のブラウザ（localStorage）にのみ保存**され、Google 以外には送信されません
- 共用のパソコンで使ったら、設定画面の「削除」を押してください
- キーなしでも、診断と文章だけの絵本は動きます（挿絵とBMCはキーが必要です）

## なぜ Gemini Storybook を使っていないのか

Gemini アプリの Storybook は Gem（アプリ内機能）であり、**プログラムから呼び出せる公開APIがありません**。
そのため「アプリで生成したテキストを人がコピーして Storybook に貼る」という手作業が必ず発生します。

このアプリは Storybook を経由せず、**Gemini API を直接呼んで本文と挿絵をその場で生成**します。
これがコピペを不要にしている部分です。

## 全体の流れ

| ステップ | 内容 |
| --- | --- |
| 1. 夢職業診断 | 5つの質問にチャットで答える |
| 2. 職業提案 | その子だけのオリジナル職業を提案 |
| 3. 絵本づくり | 本文10ページ＋挿絵を生成し、めくり式で読む |
| 4. おしごとの せっけいず | ビジネスモデルキャンバス9マスに展開 |

絵本と BMC は「印刷・PDF保存」から持ち帰れます。読み上げはブラウザの音声合成を使います。

## 作った絵本の保存

絵本の画面で「ほぞんする」を押すと、この端末のブラウザに保存されます。
次に開いたときトップ画面に一覧が出るので、そこから開き直せます。

挿絵を含めると1冊で数MBになり localStorage の容量（約5MB）では足りないため、
保存先には IndexedDB を使っています。保存されるのはこの端末の中だけで、どこにも送信されません。

10ページの流れは `PAGE_BEATS` で固定しています（紹介 → あこがれ → 一歩 → 小さな成功 →
壁 → 落ちこみ → 得意を思い出す → 乗りこえる → 花ひらく → 読者へのメッセージ）。
ページ数だけ増やすと話が冗長になるため、1ページ＝1つの出来事になるよう役割を決めています。

## 主人公の見た目をそろえる仕組み

ページごとに独立して絵を描かせると、主人公の顔や服が毎ページ変わってしまいます。そこで：

1. まず**キャラクター設定画**を1枚生成する（正面・横向き・顔アップの三面図、白背景）。表には出さず基準にだけ使う
2. **1ページめ**を設定画つきで生成する。これが画風の基準になる
3. **2ページめ以降**は「設定画 ＋ 1ページめ」を参照させ、**3枚ずつ並列で**生成する

10枚を1枚ずつ順番に描くと待ち時間が長すぎるため並列にしていますが、
レート制限に当たらないよう同時実行数は3に制限しています（`IMAGE_CONCURRENCY`）。
表紙には1ページめの絵を使います。

## 挿絵のモデル

| 画質 | モデル |
| --- | --- |
| 高画質（既定） | `gemini-3-pro-image`（Nano Banana Pro）。2K出力、人物の同一性保持が最も安定 |
| 速度優先 | `gemini-3.1-flash-lite-image`（Nano Banana 2 Lite）。速くて安い |

モデルIDは提供側の都合で入れ替わるため、コード内で決め打ちせず
**キーで実際に使えるモデルを `ListModels` で取得してから選び**ます。
設定画面の「使えるモデルを確認する」で一覧を取得し、手動で選ぶこともできます。

## 費用の目安

絵本1冊につき挿絵を**11枚**生成します（設定画1枚＋本文10ページ）。
高画質だと1冊あたり **$1.5 前後**です。速度優先に切り替えると大きく下がります。
教室でまとめて使う場合は、Google AI Studio 側で利用上限を設定しておくことをおすすめします。
